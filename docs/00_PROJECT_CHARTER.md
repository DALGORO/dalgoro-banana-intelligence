# 00 — Project Charter

## Nombre
DALGORO Banana Intelligence

## Objetivo
Crear una plataforma modular para transformar información espacial, agronómica,
meteorológica, productiva, SST y de empacadora en decisiones trazables para
productores y técnicos bananeros.

## Principios
1. PostgreSQL/PostGIS será la futura fuente central de datos.
2. Los tres sistemas existentes se conservarán sin cambios destructivos al inicio.
3. Toda recomendación distinguirá dato, inferencia, hipótesis y aprobación profesional.
4. Los modelos de IA no se autoactualizarán sin evaluación Champion/Challenger.
5. Nunca se almacenarán secretos, ortofotos ni datos productivos reales en Git.
6. Cada cambio se realizará mediante ticket, rama y pruebas.
